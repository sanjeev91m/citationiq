# CitationIQ

AI Citation Score Analyzer. Check whether your content can be cited by AI engines like ChatGPT, Claude, Gemini, and Perplexity.

## Getting started

```bash
cp .env.local.example .env.local
# fill in ANTHROPIC_API_KEY
npm install
npm run dev
```

Open http://localhost:3000.
